# slides-extractor

CLI-утилита: извлекает **уникальные статические слайды** из обучающих видео.

Типичный сценарий — запись экрана / screencast, где «видео» — это смена слайдов (PowerPoint, PDF, доска), а не непрерывный видеопоток. Скрипт находит смену кадра, ждёт стабилизации и сохраняет каждый новый слайд как картинку с порядковым номером.

## Требования

- Python 3.10+
- зависимости из `requirements.txt` (OpenCV, NumPy)

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Использование

```bash
# одно видео → рядом появится папка с именем файла
python extract_slides.py path/to/lecture.mp4
# → path/to/lecture/01.png, 02.png, …

# все видео в директории
python extract_slides.py path/to/videos/

# положить папки со слайдами в другое место
python extract_slides.py path/to/videos/ -o slides_out/
```

Поддерживаемые расширения: `.mp4`, `.mkv`, `.avi`, `.mov`, `.webm`, `.m4v`, `.wmv`.

### Параметры

| Флаг | Смысл | По умолчанию |
|------|--------|--------------|
| `path` | Видеофайл или директория с видео | — |
| `-o`, `--output-dir` | Родительская папка для результатов | рядом с каждым видео |
| `--sample-fps` | Частота выборки кадров для анализа | `2` |
| `--threshold` | Доля отличающихся пикселей → «новый слайд» | `0.03` (3%) |
| `--pixel-diff` | Порог разницы яркости пикселя (0–255) | `25` |
| `--stability` | Сколько подряд похожих выборок, чтобы зафиксировать слайд | `2` |
| `--format` | `png` / `jpg` / `jpeg` / `webp` | `png` |
| `-q`, `--quiet` | Меньше логов | off |

### Тонкая настройка

- **Слишком много дублей / шум / анимация** — увеличьте `--threshold` (например `0.05`).
- **Пропускает смену слайда** — уменьшите `--threshold` (например `0.015`) или поднимите `--sample-fps`.
- **Ловит кадры посередине перехода** — увеличьте `--stability` (например `3`–`4`).

Повторный запуск по тому же видео **перезаписывает** нумерованные картинки в выходной папке.

## Как это устроено

1. Открывает видео через OpenCV.
2. Берёт кадры с шагом `source_fps / sample_fps` (по умолчанию ~2 кадра/с).
3. Сравнивает текущий кадр с последним сохранённым слайдом (доля пикселей с заметной разницей яркости).
4. Если кадр новый, ждёт `stability` подряд похожих выборок — чтобы не сохранять полупрозрачный переход.
5. Пишет `01.<format>`, `02.<format>`, … в директорию с именем видео (без расширения).

## Локальные данные

Папка `videos/` (исходники и результаты прогонов) **не коммитится** — см. `.gitignore`. Положите туда свои файлы и запускайте:

```bash
python extract_slides.py videos/
```
